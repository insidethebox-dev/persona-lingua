# Dyslexic-Friendly Fonts

Place your dyslexic-friendly font files in this directory. The system will automatically detect and use them.

## Supported Font Formats

- **TTF** (TrueType Font) - `.ttf`
- **OTF** (OpenType Font) - `.otf`
- **WOFF** (Web Open Font Format) - `.woff`
- **WOFF2** (Web Open Font Format 2) - `.woff2`

## Recommended Fonts

### OpenDyslexic

- Download from: https://opendyslexic.org/
- Files: `OpenDyslexic-Regular.ttf`, `OpenDyslexic-Bold.ttf`

### Lexie Readable

- Download from: https://www.k-type.com/fonts/lexie-readable/
- Files: `LexieReadable-Regular.ttf`

### Dyslexie Font

- Commercial font from: https://www.dyslexiefont.com/
- Files: `Dyslexie-Regular.ttf`

## Font Installation

1. Download your preferred dyslexic-friendly font
2. Place the font files in this directory
3. The system will automatically detect and use them
4. Update the `CUSTOM_DYSLEXIC_FONTS` array in `dyslexic-formatting.ts` if needed

## File Naming Convention

Use clear, descriptive names for your font files:

- `OpenDyslexic-Regular.ttf`
- `OpenDyslexic-Bold.ttf`
- `LexieReadable-Regular.ttf`

## Usage

Once fonts are installed, they will be available in the dyslexic formatting presets and can be selected through the application interface.
